项目经历

ProGhostty - 面向 AI CLI 开发者的现代 macOS 终端 官网: ghostty.praw.top

独立开源项目

原生现代 macOS 终端；对比 cmux、Ghostty、MacTerm 后，探索在保留传统终端实时交互的同时实现像素级历史滚动。

  • 内核集成：自行解析 ANSI 意味着长期追平终端语义；集成 Ghostty libghostty-vt 作为唯一终端语义源，Swift 层只构建 macOS 交互、渲染、滚动与工作区层，保留真实 PTY 交互。
  • 渲染选型：评估并放弃 NSTextView 与 HTML 渲染方案，设计“整行切换历史记录，不足一行由 GPU 像素平移”的 Metal 模型，结合屏外 overscan 与裁剪避免边缘缺行。
  • 滚动架构：为解决 AI CLI 持续输出时历史阅读位置被拉走的问题，将滚动拆为纯值引擎、绝对行解析与历史窗口三层；随 scrollback 增长平移浏览坐标系，使新输出持续追加而当前阅读位置保持稳定，核心逻辑可独立单测。
  • 架构守卫：以不可变快照、协议边界及 App → Core → PTY → VT → Renderer 单向依赖约束状态所有权，架构守卫接入 CI；11 周发布 35 个版本，覆盖滚动、VT 桥接、分屏与输入状态。源仓库：github.com/freecodetiger/ProGhostty
